# Política de Seguridad

## Versiones compatibles

Este proyecto es un sitio web estático que se publica desde la rama `main`.
Solo se da soporte y se aplican correcciones de seguridad a la versión
publicada actualmente (la última versión de `main`).

| Versión                   | Soporte            |
| ------------------------- | ------------------ |
| Rama `main` (actual)      | :white_check_mark: |
| Versiones anteriores      | :x:                |

## Cómo reportar una vulnerabilidad

Si encontrás un problema de seguridad, por favor **no lo publiques en un
issue público**. Reportalo de forma privada de una de estas maneras:

- Desde la pestaña **Security** del repositorio, con la opción
  **Report a vulnerability** (reporte privado de GitHub).
- Por correo electrónico a: **clara@mundoponi.com**

Incluí en el reporte, si es posible:
- Una descripción del problema.
- Los pasos para reproducirlo.
- La página o archivo afectado.

### Qué podés esperar

- **Respuesta inicial:** dentro de los 7 días hábiles posteriores al reporte.
- **Actualizaciones:** te iremos informando del avance al menos una vez
  cada 14 días.
- **Si la vulnerabilidad es aceptada:** trabajaremos en una corrección,
  la publicaremos lo antes posible y te avisaremos cuando esté resuelta.
- **Si la vulnerabilidad es rechazada:** te explicaremos el motivo
  (por ejemplo, si no es reproducible o no representa un riesgo real).

¡Gracias por ayudar a mantener este proyecto seguro!
